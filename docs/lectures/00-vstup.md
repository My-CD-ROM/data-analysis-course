## З чого складається назва курсу

**Аналіз даних** — методи, які дозволяють дослідити вже наявні дані: описова
статистика, візуалізація, перевірка гіпотез. Відповідає на питання
*«що показують дані?»*.

**Математичне моделювання** — побудова формалізованого представлення процесу
чи явища, яке дозволяє пояснити механізм, спрогнозувати результат або
оптимізувати рішення. Відповідає на питання *«як це працює і що буде далі?»*.

Ці дві складові не існують окремо: аналіз даних готує й перевіряє матеріал
для моделі, а модель перетворює дані на висновок, прогноз чи рішення.

## Предмет і задачі — «Дані» і «Модель»

Дані самі по собі — це просто числа, тексти, категорії: виміряні або
зафіксовані факти. Наприклад, температура за кожен день року — це дані. Але
сама температура за 365 днів нічого не скаже про те, чи буде завтра дощ.

Модель — спосіб перетворити ці дані на висновок, оцінку чи прогноз,
статистичний або математичний. Задача курсу — навчитись проходити цей шлях
свідомо: від сирих даних до обґрунтованого висновку чи робочої моделі.

## Життєвий цикл аналізу даних

Шість кроків, які повторюються знову і знову, щоразу з новими методами:

1. **Постановка задачі** — яке питання ми ставимо, перш ніж щось рахувати.
2. **Збір даних** — звідки беремо інформацію, у якому форматі, наскільки їй
   можна довіряти.
3. **Чищення** — реальні дані майже завжди «брудні»: пропуски, дублікати,
   помилки введення.
4. **Опис і візуалізація** — подивитись на дані: значення, розподіли,
   залежності.
5. **Висновок або модель** — застосовуються статистичні критерії або
   математичні моделі, залежно від задачі. Результат тут — технічний: число,
   коефіцієнт, статистика, формула.
6. **Інтерпретація** — переклад цього технічного результату назад у сенс
   задачі, з якої все почалось: що це число означає для реальної проблеми і
   що з цим робити далі.

## Python і середовища розробки

Мова програмування курсу — Python. Середовище розробки — місце, де фізично
пишеться й запускається код:

- **Jupyter Notebook** — класичний інтерфейс із клітинками: код виконується
  частинами, результат видно одразу під кожною клітинкою.
- **Google Colab** — та сама ідея, але в браузері, без встановлення на
  комп'ютер. Основне середовище курсу — однакове для всіх незалежно від
  того, який комп'ютер у студента, і вже має весь потрібний стек бібліотек.
- **VS Code** — популярний редактор, альтернатива для дому чи професійної
  роботи (потребує розширень **Python** і **Jupyter**).

Чому саме клітинки, а не звичайний скрипт: аналіз даних — процес ітеративний,
а не написання програми від початку до кінця. Ноутбук дозволяє виконувати
код по клітинках і одразу бачити результат під кожною з них, без перезапуску
всього скрипта — це прямо повторює життєвий цикл аналізу даних. Ноутбук
також поєднує код, результат і текстове пояснення в одному документі — це
той самий формат, у якому зрештою здається фінальний звіт по наскрізному
проєкту.

## Бібліотеки наукового Python-стеку

| Бібліотека | Для чого |
|---|---|
| **NumPy** | масиви й векторизовані обчислення; база, на якій побудовані всі інші |
| **pandas** | таблиці даних: завантажити, відфільтрувати, згрупувати |
| **Matplotlib** | графіки та візуалізація |
| **SciPy** | розподіли ймовірностей, статистичні тести, оптимізація — знадобиться під час перевірки гіпотез |
| **statsmodels** | статистичне моделювання й регресія з повним поясненням (значущість коефіцієнтів, довірчі інтервали, R²), а не лише прогноз |

**SciPy** — надбудова над NumPy з готовими науковими алгоритмами. Коли треба
перевірити гіпотезу — наприклад, чи різниця між двома групами не випадкова —
саме SciPy рахує це за нас.

**statsmodels** — на відміну від "просто прогнозної" бібліотеки, дає не
тільки число-прогноз, а й пояснення: чи значущий коефіцієнт, з якою
невизначеністю, наскільки модель узагалі описує дані.

### Демонстрація: однаковий код у трьох середовищах

Один і той самий приклад, вставлений у Jupyter Notebook, Google Colab і
VS Code — результат (таблиця й графік) з'являється однаково в усіх трьох:

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

months = ["Січ","Лют","Бер","Кві","Тра","Чер","Лип","Сер","Вер","Жов","Лис","Гру"]
avg_temp = np.array([-4,-3,2,9,15,19,21,20,14,8,2,-2])

df = pd.DataFrame({"month": months, "avg_temp": avg_temp})
print(df)
print("Найтепліший місяць:", df.loc[df["avg_temp"].idxmax(), "month"])

plt.plot(df["month"], df["avg_temp"], marker="o")
plt.title("Середньомісячна температура")
plt.ylabel("°C")
plt.show()
```

!!! note "Класичний Jupyter Notebook"
    Якщо графік не з'явився одразу під клітинкою, спробуйте додати рядок
    `%matplotlib inline` перед побудовою графіка (у Colab і VS Code це не
    потрібно).
