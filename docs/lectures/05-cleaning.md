# Лекція 5. Чищення даних

!!! info "Матеріали в підготовці"
    Ця сторінка — заготовка. Конспект з'явиться тут після проведення заняття.

**За навчальною програмою:** Чищення даних: пропуски, дублікати, типи,
кодування. Викиди й аномальні значення.

**Обсяг:** 2 лекційні години.
