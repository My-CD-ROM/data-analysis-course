# Лекція 19. Поняття математичної моделі й етапи моделювання

!!! info "Матеріали в підготовці"
    Ця сторінка — заготовка. Конспект з'явиться тут після проведення заняття.

**За навчальною програмою:** Поняття математичної моделі й етапи моделювання. Класифікація математичних моделей (детерміновані, стохастичні, балансові, оптимізаційні, імітаційні), адекватність, верифікація і валідація.

**Обсяг:** 2 лекційні години.

**Практика до цієї лекції:** [Практика 19. Класифікація математичних моделей: аналіз прикладів, перевірка адекватності моделі](../practice/19-model-adequacy.md)
