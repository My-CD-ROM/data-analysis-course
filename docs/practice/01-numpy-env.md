## Приклад: наскрізна демонстрація

Перш ніж виконувати завдання на власному варіанті, розберіть цей приклад —
він показує ті самі прийоми на іншому, демонстраційному наборі (вологість
повітря за 8 днів спостережень, у %). Завдання нижче — та сама техніка,
але на ваших даних, тож просто скопіювати цей код для власного варіанта не
вийде.

```python
humidity = np.array([42, 55, 61, 38, 47, 66, 59, 44])
humidity.shape   # (8,)
humidity.dtype   # dtype('int64')

# векторизована операція — переведення відсотків у частку, без циклу
humidity_frac = humidity / 100

# булева індексація — тільки дні з вологістю вище 50%
humid_days = humidity[humidity > 50]

# argmax/argmin — індекс найвологішого й найсухішого дня
humidity.argmax()   # 5
humidity.argmin()   # 3

# сортування без зміни оригінального масиву
np.sort(humidity)

# другий рядок вимірювань — температура за ті самі 8 днів
temperature = np.array([18, 20, 19, 22, 21, 17, 23, 20])
data = np.array([humidity, temperature])

data.mean(axis=1)   # середнє по кожному рядку (окремо вологість, окремо температура)
data.sum(axis=0)    # сума по кожному дню (по стовпцях)
```

## Завдання 1. Створення масивів

За таблицею свого варіанта створіть:

1. `temps` — масив температур свого варіанта.
2. `days_in_month` — кількість днів у кожному місяці (не високосний рік).
3. `month_numbers` — номери місяців від 1 до 12, через `np.arange`.

Виведіть `shape` і `dtype` для всіх трьох масивів.

## Завдання 2. Векторизовані обчислення

1. Переведіть `temps` із °C у °F **без циклу**, однією векторизованою
   операцією (формула: `°F = °C × 9/5 + 32`).
2. Обчисліть, скільки всього днів у році тепліше 15°C, поєднавши булеву
   індексацію `temps` і `days_in_month` (без циклу).
3. Перевірте, що сума `days_in_month` дорівнює 365.

## Завдання 3. Індексація і фільтрація

1. Знайдіть значення й індекс найтеплішого та найхолоднішого місяця.
2. Виведіть номери місяців, де температура нижче нуля, використовуючи
   булеву індексацію по `month_numbers`.
3. Виведіть температури, відсортовані за зростанням, без зміни порядку в

## Завдання 4. Двовимірний масив і `axis`

1. Додайте третій рядок даних на власний розсуд, пов'язаний із вашим
