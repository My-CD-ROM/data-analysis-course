## Приклад: наскрізна демонстрація

Розберіть цей приклад на демонстраційному наборі — квартальна виручка
трьох умовних магазинів — перш ніж виконувати завдання на своєму
варіанті.

```python
import pandas as pd

wide = pd.DataFrame({
    "магазин": ["Центр", "Північний", "Південний"],
    "Q1": [120_000, 95_000, 88_000],
    "Q2": [135_000, 101_000, 92_000],
    "Q3": [128_000, 98_000, 95_000],
    "Q4": [160_000, 112_000, 110_000],
})

# wide -> tidy (long): квартал стає значенням, а не назвою стовпця
tidy = wide.melt(id_vars="магазин", var_name="квартал", value_name="виручка")

# tidy -> wide: обернена операція, зручна для звіту
back = tidy.pivot(index="магазин", columns="квартал", values="виручка")

# запис і читання у двох форматах
tidy.to_csv("demo_tidy.csv", index=False)
tidy.to_json("demo_tidy.json", orient="records", force_ascii=False)

reloaded_csv = pd.read_csv("demo_tidy.csv")
reloaded_json = pd.read_json("demo_tidy.json")
```

Зверніть увагу: `wide.melt()` перетворює 3 рядки × 5 стовпців (магазин +
4 квартали) на 12 рядків × 3 стовпці (магазин, квартал, виручка) — кожен
раніше окремий стовпець тепер став одним значенням у стовпці "квартал".
