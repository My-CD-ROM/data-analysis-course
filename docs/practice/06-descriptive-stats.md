## Приклад: наскрізна демонстрація

Розберіть цей приклад — щоденна кількість замовлень у двох філіях кав'ярні
за тиждень (**не** ваш варіант і не тема регіонів вологості) — перш ніж
переходити до завдань на власних даних.

```python
import pandas as pd

orders = pd.DataFrame({
    "філія":     ["Центр"] * 6 + ["Спальний район"] * 6,
    "замовлень": [120, 135, 128, 142, 130, 138,
                  95, 88, 102, 91, 97, 85],
})

orders["замовлень"].describe()
```

Виклик `.describe()` на всьому стовпці одразу дає всі основні міри
положення й розсіювання з лекції 6:

```text
count     12.000000
mean      112.583333
std        21.540000    # це і є std усього об'єднаного стовпця
min        85.000000    # використовується для розмаху (max - min)
25%        94.000000     # разом із 75% дає IQR
50%       111.000000    # медіана
75%       131.250000
max       142.000000
```

Ці самі числа можна отримати вручну — саме так `describe()` рахує їх
"під капотом":

```python
s = orders["замовлень"]

rozmakh = s.max() - s.min()          # розмах
std = s.std()                         # ddof=1 за замовчуванням у pandas
q1, q3 = s.quantile([0.25, 0.75])
iqr = q3 - q1
cv = std / s.mean() * 100             # коефіцієнт варіації, %
```

Тепер — порівняння двох філій **без** `groupby()`, лише булевою
фільтрацією підмножин:

```python
center = orders[orders["філія"] == "Центр"]["замовлень"]
sleeping = orders[orders["філія"] == "Спальний район"]["замовлень"]

center.describe()
sleeping.describe()
```

Приблизний результат:

```text
# Центр:            mean ≈ 132.17   std ≈ 7.86   min 120   max 142
# Спальний район:   mean ≈ 93.00    std ≈ 6.23   min 85    max 102
```

Абсолютний std філії "Центр" (≈7.86) більший за std "Спального району"
(≈6.23) — на перший погляд, "Центр" розкиданіший. Але середні у філій
геть різні (132 проти 93), тому це порівняння некоректне без нормування
(Лекція 6). Коефіцієнт варіації показує іншу картину:

```python
cv_center = center.std() / center.mean() * 100     # ≈ 5.95%
cv_sleeping = sleeping.std() / sleeping.mean() * 100  # ≈ 6.70%
```

Відносно власного середнього "Спальний район" насправді трохи
**варіативніший**, ніж "Центр", хоча його абсолютний std менший —
класична ситуація, де порівняння "на око" за сирим std веде до
хибного висновку. Зверніть увагу й на форму: у обох філій значення
розташовані плюс-мінус рівномірно навколо своєї медіани (значення `50%`
близькі до `mean`), тобто розподіл кожної філії ближчий до симетричного,
і середнє тут не менш репрезентативне за медіану.

## Підсумок заняття

- `.describe()` дав одним викликом усі основні міри положення й
  розсіювання, а ручне обчислення показало, що саме стоїть за кожним із
  цих чисел.
- Порівняння підмножин за регіоном через булеву фільтрацію
  (`df[df["регіон"] == "..."]`) дало ту саму описову статистику для
  кожної групи окремо, без `groupby()`.
- Коефіцієнт варіації застосований для коректного порівняння розкиду
  між групами й містами різного масштабу, а форма власного розподілу —
  для вибору репрезентативнішої міри положення.
