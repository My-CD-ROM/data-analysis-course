## Основи: Figure, Axes і об'єктний інтерфейс

**Figure** — це вікно чи "аркуш" цілком, **Axes** — конкретна область
на ньому з осями, підписами й самим графіком; одна Figure може містити
кілька Axes (кілька графіків поруч). Об'єктний інтерфейс Matplotlib
явно створює обидва об'єкти й керує ними напряму — саме цей стиль
використовується в завданнях нижче:

```python
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(6, 4))   # одна Figure, одна Axes
ax.hist(дані, bins=10)
ax.set_xlabel("...")
ax.set_ylabel("...")
ax.set_title("...")
plt.show()
```

`plt.subplots(nrows, ncols)` створює одразу кілька Axes в одній Figure
(потрібно нижче для порівняння "правильний/спотворений" графік поруч).

## Приклад: наскрізна демонстрація

Розберіть цей приклад — відвідуваність спортзалу за 20 днів — перш ніж
будувати графіки на своєму варіанті. Дані й висновки тут навмисно інші,
щоб просто скопіювати код без розуміння не вийшло.

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

np.random.seed(0)
days = np.arange(1, 21)
weekend = np.isin(days % 7, [6, 0])                       # умовно вихідні дні
temperature = np.round(np.random.normal(15, 4, size=20), 1)
visitors = np.round(
    60 + weekend * 25 - (temperature - 15) * 1.5 + np.random.normal(0, 5, size=20)
).astype(int)

gym = pd.DataFrame({"день": days, "вихідний": weekend,
                     "температура": temperature, "відвідувачі": visitors})

# 1. гістограма — розподіл кількості відвідувачів за 20 днів
fig, ax = plt.subplots(figsize=(6, 4))
ax.hist(gym["відвідувачі"], bins=6, edgecolor="white")
ax.set_xlabel("Кількість відвідувачів за день")
ax.set_ylabel("Кількість днів")
ax.set_title("Розподіл відвідуваності спортзалу за 20 днів")
plt.show()

# 2. boxplot — порівняння відвідуваності в будні й вихідні
fig, ax = plt.subplots(figsize=(5, 4))
groups = [gym.loc[~gym["вихідний"], "відвідувачі"], gym.loc[gym["вихідний"], "відвідувачі"]]
ax.boxplot(groups, labels=["Будній", "Вихідний"])
ax.set_ylabel("Кількість відвідувачів")
ax.set_title("Відвідуваність: будні проти вихідних")
plt.show()

# 3. діаграма розсіювання — відвідувачі проти температури
fig, ax = plt.subplots(figsize=(5, 4))
ax.scatter(gym["температура"], gym["відвідувачі"])
ax.set_xlabel("Температура повітря, °C")
ax.set_ylabel("Кількість відвідувачів")
ax.set_title("Відвідуваність спортзалу проти температури повітря")
plt.show()
```

Зверніть увагу: кожен графік має підпис обох осей з одиницями, заголовок
і жодного зайвого кольору чи 3D-ефекту — це не окремий крок "оздобити
графік наприкінці", а частина коректної побудови з самого початку.

## Підсумок заняття

- Об'єктний інтерфейс Matplotlib (`fig, ax = plt.subplots()`) застосований
  для побудови гістограми, boxplot і діаграми розсіювання на власних
  даних.
- Кожен графік підписаний (осі, одиниці, заголовок) як обов'язкова
  частина побудови, а не окремий "косметичний" крок.
- Один принцип коректної візуалізації з Лекції 7 навмисно порушений і
  письмово проаналізований — щоб побачити механізм спотворення на
  власному прикладі, а не лише прочитати про нього.
