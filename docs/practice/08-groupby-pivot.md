## Приклад: наскрізна демонстрація

Розберіть цей приклад — виручка мережі з трьох кав'ярень за квартали
двох років — перш ніж виконувати завдання на кліматичному наборі свого
варіанта.

```python
cafe = pd.DataFrame({
    "філія":   ["Центр", "Центр", "Центр", "Центр", "Центр", "Центр", "Центр", "Центр",
                 "Вокзал", "Вокзал", "Вокзал", "Вокзал", "Вокзал", "Вокзал", "Вокзал", "Вокзал",
                 "Парк", "Парк", "Парк", "Парк", "Парк", "Парк", "Парк", "Парк"],
    "рік":     [2023]*4 + [2024]*4 + [2023]*4 + [2024]*4 + [2023]*4 + [2024]*4,
    "квартал": [1, 2, 3, 4]*6,
    "виручка": [180, 210, 260, 190, 195, 225, 275, 205,
                140, 150, 210, 160, 145, 158, 220, 168,
                90, 130, 175, 100, 95, 138, 182, 108],
})

# groupby + agg: кілька статистик одразу для кожної філії
cafe.groupby("філія")["виручка"].agg(["mean", "std", "count"])

# pivot() ламається: на комбінацію (філія, рік) припадає 4 квартали, а не 1
cafe.pivot(index="філія", columns="рік", values="виручка")   # ValueError: Index contains duplicate entries

# pivot_table() не ламається — агрегує 4 квартали в одне число через aggfunc
cafe.pivot_table(index="філія", columns="рік", values="виручка", aggfunc="sum")
#          2023  2024
# філія
# Вокзал    660   671
# Парк      495   523
# Центр     840   900

# crosstab: додаємо категорію "прибутковий квартал" і рахуємо частоти за філією
cafe["прибутковий"] = cafe["виручка"] > cafe["виручка"].median()
pd.crosstab(cafe["філія"], cafe["прибутковий"])
```

Саме різниця між `pivot()` і `pivot_table()` тут показова: для пари
(філія, рік) є чотири рядки (по кварталу), тож `pivot()` не знає, яке з
чотирьох значень покласти в одну клітинку, і завершується помилкою;
`pivot_table()` явно каже, як звести чотири значення в одне (`aggfunc="sum"`),
і працює.

## Підсумок заняття

- Довгий (tidy) набір із чотирма роками й дванадцятьма місяцями
  побудований і використаний для `groupby`, `.agg()`, `pivot_table()` і
  `crosstab()` — саме в цьому форматі ці інструменти працюють як
  задумано.
- Групування за роком і за місяцем застосоване для пошуку тренду й
  нестабільності відповідно, з кількома статистиками одним `.agg()`.
- Принципова відмінність `pivot()` і `pivot_table()` перевірена не
  тільки на готовому прикладі, а й на власних даних — де за умовою
  немає дублікатів, і `pivot()` спрацьовує.
