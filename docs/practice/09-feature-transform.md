## Приклад: наскрізна демонстрація

Розберіть цей приклад — оренда квартир у демонстраційному місті — перш ніж
виконувати завдання на своєму інтернет-магазині. Це той самий набір
прийомів, але на іншому наборі даних, тож просто скопіювати код не вийде.

```python
import pandas as pd

flats = pd.DataFrame([
    {"район": "центр",    "площа_м2": 42, "ціна_usd": 480},
    {"район": "центр",    "площа_м2": 55, "ціна_usd": 610},
    {"район": "спальний",  "площа_м2": 60, "ціна_usd": 390},
    {"район": "спальний",  "площа_м2": 38, "ціна_usd": 260},
    {"район": "передмістя", "площа_м2": 80, "ціна_usd": 340},
    {"район": "передмістя", "площа_м2": 95, "ціна_usd": 400},
])

# 1. похідна змінна — ціна за квадратний метр несе більше сенсу,
#    ніж "ціна" і "площа" окремо: саме вона порівнянна між квартирами різного розміру
flats["ціна_за_м2"] = flats["ціна_usd"] / flats["площа_м2"]

# 2. дискретизація площі: cut — інтервали однакової довжини
flats["площа_група_cut"] = pd.cut(flats["площа_м2"], bins=3)
flats["площа_група_cut"].value_counts()

# те саме qcut — рівна кількість квартир у кожній групі, межі нерівні
flats["площа_група_qcut"] = pd.qcut(flats["площа_м2"], q=3)
flats["площа_група_qcut"].value_counts()

# 3. масштабування ціни за м2: min-max і z-оцінка
c = flats["ціна_за_м2"]
flats["ціна_за_м2_norm"] = (c - c.min()) / (c.max() - c.min())
flats["ціна_за_м2_z"] = (c - c.mean()) / c.std()

# 4. one-hot кодування району — район не має природного порядку
district_dummies = pd.get_dummies(flats["район"], prefix="район")
flats = pd.concat([flats, district_dummies], axis=1)
```

Зверніть увагу: `район` закодовано one-hot (номінальна змінна — "центр"
не "більший" за "спальний"), а не мапінгом у 1, 2, 3, який хибно вніс би
порядок між районами.

## Завдання 1. Побудова набору клієнтів

Побудуйте `DataFrame` із **10 замовленнями** свого інтернет-магазину.
Кожен рядок — один клієнт із полями:

- `вік` — вік клієнта (довільні реалістичні значення від 18 до 70 років);
- `дохід` — місячний дохід клієнта в гривнях (довільні реалістичні
  значення; свідомо іншого порядку величини, ніж вік — це знадобиться в
  Завданні 4);
- `кількість` — кількість одиниць товару в замовленні (беріть базову
  кількість свого варіанта як орієнтир, значення можуть відрізнятись за
  рядками);
- `місто_доставки` — місто, куди відправлено замовлення; використайте
  **щонайменше 4 різні міста** з таблиці варіантів курсу серед 10 рядків
  (не лише своє місто).

## Завдання 2. Похідна змінна

Обчисліть два похідні стовпці:

1. `сума_замовлення` = базова ціна вашого варіанта × `кількість`.
2. `частка_доходу` = `сума_замовлення` / `дохід`.

Письмово поясніть, чому `частка_доходу` як окрема змінна може бути
корисніша для аналізу поведінки клієнтів, ніж `сума_замовлення` і `дохід`,
розглянуті окремо один від одного.

## Завдання 3. Дискретизація

## Завдання 4. Масштабування

1. Масштабуйте `вік` і `дохід` методом min-max нормалізації (у `[0, 1]`).
2. Масштабуйте ті самі дві змінні методом z-оцінки (стандартизація).
3. Виведіть перші кілька рядків обох варіантів поруч і письмово поясніть,

## Завдання 5. Індикаторне кодування

1. Закодуйте `місто_доставки` через `pd.get_dummies()`.

## Підсумок заняття

- Похідна змінна (`частка_доходу`) побудована тією самою механікою
  обчислюваних стовпців, що й раніше в курсі, але свідомо — заради
  додаткового сенсу, якого немає в жодному складнику окремо.
- Дискретизація застосована двома способами (`cut`, `qcut`) на одній і
  тій самій змінній, що дало змогу побачити різницю в розмірі груп
  напряму, а не лише в теорії.
- Масштабування (min-max і z-оцінка) застосоване до змінних різного
  порядку величини (вік і дохід), що готує їх до методів, чутливих до
  масштабу, які курс розгляне в модулі 3.
- Індикаторне кодування застосоване до номінальної змінної (місто
  доставки) — свідомо, а не порядковим мапінгом, який вніс би хибний
  порядок.
