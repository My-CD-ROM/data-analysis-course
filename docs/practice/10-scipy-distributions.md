## Приклад: наскрізна демонстрація

Розберіть цей приклад — оцінки 25 студентів за контрольну роботу
(100-бальна шкала) — перш ніж переходити до власного варіанта. Це інший,
демонстраційний набір: скопіювати код і підставити свої числа не вийде,
підбирати параметри доведеться для власної вибірки окремо.

```python
import numpy as np
from scipy import stats
import matplotlib.pyplot as plt

scores = np.array([62, 71, 75, 80, 68, 74, 90, 55, 77, 82, 69, 73, 85, 60, 78,
                    72, 88, 65, 76, 81, 70, 58, 83, 79, 67])

# 1. параметри нормального розподілу з власних даних
mean, std = scores.mean(), scores.std()          # 73.52, 9.01
dist = stats.norm(loc=mean, scale=std)            # теоретичний розподіл N(73.52, 9.01)

# 2. гістограма реальних даних + теоретична pdf-крива
x = np.linspace(scores.min() - 10, scores.max() + 10, 200)
plt.hist(scores, bins=8, density=True, edgecolor="white", alpha=0.7)
plt.plot(x, dist.pdf(x), color="crimson", linewidth=2)
plt.show()

# 3. ймовірність, що бал лежить у діапазоні [70, 85]
p_70_85 = dist.cdf(85) - dist.cdf(70)              # 0.551

# 4. межа для "топ-10% результатів" (90-й процентиль)
top10_cutoff = dist.ppf(0.90)                      # 85.07
```

**Що тут відбувається.** `density=True` у `plt.hist()` переводить вісь Y
з абсолютної кількості спостережень у **густину** — це і робить
гістограму сумісною з `.pdf()`, яка теж повертає густину, а не кількість:
без `density=True` криву й стовпці порівнювати було б некоректно, бо вони
вимірювались би в різних одиницях. `dist.cdf(85) - dist.cdf(70)` — це
різниця двох накопичених ймовірностей, тобто ймовірність потрапити саме
в проміжок `[70, 85]`, а не "не перевищити" одне конкретне число:
`CDF(85)` дає частку балів не вище 85, `CDF(70)` — частку не вище 70,
різниця — частку саме між ними (`0.551`, тобто трохи більше половини
класу). `dist.ppf(0.90)` — обернена операція: не "яка частка нижче 85",
а "яке значення відповідає накопиченій частці 90%" — відповідь `85.07`
означає, що за підібраною нормальною моделлю 90% балів лежать нижче
85.07, а отже поріг "топ-10%" — приблизно 85 балів і вище.

## Підсумок заняття

- Параметри нормального розподілу (`μ`, `σ`) підібрані безпосередньо з
  вибіркового середнього й стандартного відхилення власних даних.
- Гістограма реальних даних і теоретична pdf-крива накладені на одному
  графіку через узгодження одиниць (`density=True`).
- `.cdf()` застосований для обчислення ймовірності потрапляння в
  діапазон, `.ppf()` — для пошуку значення за заданою накопиченою
  ймовірністю; обидва — на власній вибірці, а не лише на прикладі.
