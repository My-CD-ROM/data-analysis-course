# Практика 11. Числові характеристики випадкової величини; закон великих чисел і ЦГТ симуляцією

*Мета заняття: симуляцією на власному варіанті переконатись, що
вибіркове середнє x̄ справді наближається до заданого теоретичного
середнього зі зростанням n (закон великих чисел), а розподіл x̄ справді
набуває нормальної форми навіть тоді, коли вихідна генеральна
сукупність — сильно скошена (центральна гранична теорема), і обчислити
стандартну похибку для кількох значень n.*

## Варіанти

Кожен варіант — своя генеральна сукупність часу очікування (у хвилинах)
для служби підтримки одного з міст (та сама канва міст, що й у
Практиках 1 і 10), змодельована **експоненційним розподілом** (Лекція
10) із власним параметром λ. Це реалістична, зумисно скошена
сукупність — саме на такій формі найкраще видно роботу ЦГТ: розподіл
самого часу очікування не дзвоноподібний, а розподіл x̄ стане
дзвоноподібним у Завданні 3.

| Варіант | Місто | λ (подій/хв) | Теоретичне E[X] = 1/λ, хв |
|---|---|---|---|
| 1 | Київ | 0.20 | 5.0 |
| 2 | Львів | 0.25 | 4.0 |
| 3 | Одеса | 0.15 | 6.7 |
| 4 | Харків | 0.30 | 3.3 |
| 5 | Дніпро | 0.18 | 5.6 |
| 6 | Чернігів | 0.22 | 4.5 |
| 7 | Івано-Франківськ | 0.28 | 3.6 |
| 8 | Полтава | 0.16 | 6.3 |
| 9 | Суми | 0.24 | 4.2 |
| 10 | Ужгород | 0.20 | 5.0 |

λ тут — той самий параметр експоненційного розподілу з Лекції 10:
більше λ означає коротше типове очікування. Це **теоретичний**
параметр вашого варіанта — ви його знаєте наперед (на відміну від
реального аналітика), і саме тому зможете напряму перевірити, наскільки
близько симуляція підводить x̄ до цього відомого значення.

## Приклад: наскрізна демонстрація

Розберіть приклад на іншій величині — часі між покупками в
інтернет-магазині (λ = 0.4, тобто теоретичне середнє 2.5 хв) — перш ніж
переходити до власного варіанта. Це демонстраційні числа: підставити
свою λ замість 0.4 і здати такий код — не мета завдання, потрібна саме
ваша λ з таблиці варіантів.

```python
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(1)
lam_demo = 0.4
true_mean_demo = 1 / lam_demo                 # 2.5

# 1. ЗВЧ: як x̄ наближається до true_mean_demo зі зростанням n
for n in [5, 50, 5_000]:
    sample = rng.exponential(scale=1 / lam_demo, size=n)
    print(n, sample.mean())

# 2. ЦГТ: розподіл x̄ при повторній вибірці для двох значень n
n_repeats = 10_000
means_n10 = rng.exponential(scale=1 / lam_demo, size=(n_repeats, 10)).mean(axis=1)
means_n200 = rng.exponential(scale=1 / lam_demo, size=(n_repeats, 200)).mean(axis=1)

fig, axes = plt.subplots(1, 2, figsize=(10, 3.5))
axes[0].hist(means_n10, bins=40, density=True)
axes[0].set_title(f"n=10, std={means_n10.std():.3f}")
axes[1].hist(means_n200, bins=40, density=True)
axes[1].set_title(f"n=200, std={means_n200.std():.3f}")
plt.show()

# 3. стандартна похибка: теоретична формула проти виміряної симуляцією
se_theoretical_n200 = true_mean_demo / np.sqrt(200)   # σ = 1/λ для експоненційного розподілу
print(se_theoretical_n200, means_n200.std())
```

**Що тут відбувається.** `rng.exponential(scale=1/lam_demo, size=(n_repeats,
n))` за один виклик генерує матрицю `n_repeats × n` — тобто одразу
`n_repeats` окремих вибірок розміру `n`; `.mean(axis=1)` рахує середнє
кожного **рядка** окремо, залишаючи масив довжини `n_repeats` — це і є
`n_repeats` реалізацій x̄, зібраних без явного циклу `for`. Гістограма
цього масиву — не розподіл окремих спостережень, а розподіл самого
x̄ (те, що теорія називає "вибірковим розподілом середнього"). Для
експоненційного розподілу стандартне відхилення σ дорівнює тому самому
1/λ, що й середнє (властивість саме цього розподілу), тож теоретична
SE = σ/√n рахується напряму й порівнюється з `.std()` реально
згенерованих x̄ — вони мають бути близькі, якщо `n_repeats` достатньо
велике.

## Підсумок заняття

- На власній λ (експоненційний розподіл) практично підтверджено, що
  x̄ зі зростанням n наближається до відомого теоретичного E[X] —
  закон великих чисел не абстракція, а перевірюваний факт.
- Побудовано вибірковий розподіл x̄ для кількох n і візуально показано
  перехід від скошеної форми (мала n) до дзвоноподібної (велика n) —
  центральна гранична теорема в дії.
- Обчислена й порівняна з симуляцією стандартна похибка SE = σ/√n, а
  також перевірено на числах закон убуваючої віддачі — вчетверо більша
  вибірка потрібна для вдвічі меншої похибки.
