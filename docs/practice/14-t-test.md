## Приклад: наскрізна демонстрація

Розберіть цей приклад — оцінки за домашні завдання двох груп студентів і
перевірка нормативу тривалості дзвінка підтримки (**не** ваш варіант і
не тема вологості) — перш ніж переходити до завдань на власних даних.

```python
import numpy as np
from scipy import stats

# 1. Одновибірковий критерій: чи середня тривалість дзвінка (хв)
# відрізняється від нормативу SLA = 6.0 хв?
calls = np.array([6.8, 5.9, 7.2, 6.5, 7.8, 6.1, 7.0, 6.9, 7.5, 6.3])

t_stat, p_value = stats.ttest_1samp(calls, popmean=6.0)
print(t_stat, p_value)     # t ≈ 3.86, p ≈ 0.004
```

При α = 0.05 маємо `p_value ≈ 0.004 < 0.05` — відхиляємо H0: середня
тривалість дзвінка статистично значуще перевищує норматив 6.0 хв.

```python
# 2. Двовибірковий критерій: групи A і B, різні студенти, бали за тест
group_a = np.array([78, 82, 75, 88, 91, 84, 79, 86])
group_b = np.array([72, 68, 74, 90, 65, 95, 60, 88])

# Крок 1 — перевірка рівності дисперсій, ПЕРШ ніж обирати варіант t-критерію
stat_lev, p_lev = stats.levene(group_a, group_b)
print(stat_lev, p_lev)     # p_lev ≈ 0.03 -- дисперсії статистично різні

# Крок 2 — раз дисперсії різні (p_lev < 0.05), застосовуємо Welch-варіант
t_stat, p_value = stats.ttest_ind(group_a, group_b, equal_var=False)
print(t_stat, p_value)
```

Група B має видимо більший розкид балів (60 і 95 поруч із 65–90), тоді
як група A розкидана значно рівномірніше. Критерій Лівена підтверджує
це формально (`p_lev ≈ 0.03 < 0.05`), тож застосований саме Welch-варіант
(`equal_var=False`), а не стандартний — так, як і має бути за
деревом рішень з лекції: спершу Лівен, і лише за його результатом
обирається конкретна формула `ttest_ind`. Якби Лівен показав `p_lev ≥
0.05`, коректним був би стандартний варіант (`equal_var=True`).
