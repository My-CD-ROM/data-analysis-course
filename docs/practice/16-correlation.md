*Мета заняття: побудувати діаграму розсіювання для пари змінних
власного варіанта, обчислити коефіцієнти кореляції Пірсона і Спірмена
(`scipy.stats.pearsonr`, `scipy.stats.spearmanr`, Лекція 16), порівняти
їх і письмово інтерпретувати, а також побудувати кореляційну матрицю
для трьох змінних одразу (`pandas.DataFrame.corr()`). Це заняття прямо
продовжується в Практиці 17: там для цієї самої пари змінних буде
побудоване рівняння регресії.*

**Код побудови набору** (підставте своє місто й свій рядок температур
— це лише генерація вихідних даних, самі завдання виконуються нижче):

```python
import numpy as np
import pandas as pd

np.random.seed(<номер вашого варіанта>)
city = "..."
monthly_temp = [...]   # 12 значень вашого варіанта, Січ..Гру

months = ["Січ", "Лют", "Бер", "Кві", "Тра", "Чер",
          "Лип", "Сер", "Вер", "Жов", "Лис", "Гру"]

rows = []
for month, temp in zip(months, monthly_temp):
    heating_days = np.clip(18 - temp + np.random.normal(0, 1.5), 0, 30)
    heating_days = round(heating_days)
    cost = 0.15 * heating_days + np.random.normal(0, 1.0)
    cost = round(max(cost, 0), 1)
    rows.append({
        "місто": city, "місяць": month, "температура": temp,
        "опалювальні_дні": heating_days, "витрати_на_опалення": cost,
    })

climate = pd.DataFrame(rows)   # 12 рядків -- один на кожен місяць
```

## Приклад: наскрізна демонстрація

Розберіть цей приклад — рекламний бюджет і кількість продажів 12
магазинів мережі — **не** копіюйте на свій варіант: тема інша,
кореляційний аналіз демонструється лише як прийом, а обчислення на
власних кліматичних даних потрібно робити окремо.

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from scipy.stats import pearsonr, spearmanr

ad_budget = np.array([5, 8, 10, 12, 15, 18, 20, 22, 25, 28, 30, 33])   # тис. грн
sales = np.array([81, 68, 82, 95, 94, 116, 124, 111, 157, 165, 158, 177])  # шт.

fig, ax = plt.subplots()
ax.scatter(ad_budget, sales)
ax.set_xlabel("Рекламний бюджет, тис. грн")
ax.set_ylabel("Кількість продажів, шт.")
ax.set_title("Продажі залежно від рекламного бюджету (12 магазинів)")

r = pearsonr(ad_budget, sales)
rho = spearmanr(ad_budget, sales)
print(f"Пірсон: r={r.statistic:.3f}, p={r.pvalue:.2e}")
print(f"Спірмен: rho={rho.statistic:.3f}, p={rho.pvalue:.2e}")
```

Результат: `r ≈ 0.960` (p ≈ 7.5·10⁻⁷), `rho ≈ 0.958` (p ≈ 9.5·10⁻⁷).

**Що тут відбувається.** Обидва коефіцієнти показують дуже сильний,
статистично значущий позитивний зв'язок, і вони близькі одне до
одного за величиною — це очікувано, коли зв'язок і справді приблизно
лінійний (як показує діаграма розсіювання): за таких умов Пірсон і
Спірмен майже завжди узгоджуються. Мале p-value (≈ 10⁻⁶) означає, що
H0 "справжня кореляція в генеральній сукупності дорівнює нулю"
відхиляється — на 12 спостереженнях зв'язок такої сили майже напевно
не випадковий шум. **Важливе застереження, яке не можна пропускати:**
навіть така сильна кореляція сама по собі не доводить, що саме
рекламний бюджет **спричиняє** продажі — можливий і зворотний
причинно-наслідковий зв'язок (магазини з вищими продажами отримують
більший бюджет на наступний період за рішенням керівництва), і
можливий спільний конфаундер (сезон, розмір магазину). Коефіцієнт
кореляції відповідає лише на питання "чи є зв'язок і наскільки
сильний", а не "хто на кого впливає".

- Наведіть приклад ситуації (не з цієї практики), де `r ≈ 0`, а зв'язок
  між змінними насправді є і навіть сильний — і поясніть, чому Пірсон
  його не показує.
- Чому сама по собі сильна кореляція між двома змінними не є доказом,
  що одна з них впливає на іншу?

Оцінюється коректність побудови діаграми розсіювання й обох
коефіцієнтів кореляції саме на власному варіанті (а не на прикладі з
рекламним бюджетом), а також повнота письмової інтерпретації — сам
факт запуску `pearsonr()`/`spearmanr()` без пояснення результату не
вважається виконаним завданням. Окремо оцінюється Завдання 4: відповідь
має явно посилатись на те, як побудований код генерації даних, а не
обмежуватись загальною фразою "кореляція не є причинністю" без
застосування її до конкретного випадку.
