**Код побудови набору** (той самий, що в Практиці 16 — якщо ноутбук
продовжує той самий, `climate` уже готовий; якщо це новий ноутбук,
підставте своє місто й свій рядок температур):

```python
import numpy as np
import pandas as pd

np.random.seed(<номер вашого варіанта>)
city = "..."
monthly_temp = [...]   # 12 значень вашого варіанта, Січ..Гру

months = ["Січ", "Лют", "Бер", "Кві", "Тра", "Чер",
          "Лип", "Сер", "Вер", "Жов", "Лис", "Гру"]

rows = []
for month, temp in zip(months, monthly_temp):
    heating_days = np.clip(18 - temp + np.random.normal(0, 1.5), 0, 30)
    heating_days = round(heating_days)
    cost = 0.15 * heating_days + np.random.normal(0, 1.0)
    cost = round(max(cost, 0), 1)
    rows.append({
        "місто": city, "місяць": month, "температура": temp,
        "опалювальні_дні": heating_days, "витрати_на_опалення": cost,
    })

climate = pd.DataFrame(rows)
```

## Приклад: наскрізна демонстрація

Розберіть цей приклад — площа квартири й ціна оренди для 12 квартир
одного району — **не** копіюйте на свій варіант: обчислення для
власного набору "температура / витрати на опалення" виконуються
окремо в завданнях нижче.

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import linregress

area = np.array([28, 32, 35, 40, 45, 48, 52, 58, 63, 68, 75, 82])          # м²
rent = np.array([14.5, 13.6, 13.9, 12.4, 16.2, 16.9,
                  18.4, 19.3, 21.6, 22.3, 23.0, 28.3])                     # тис. грн/міс

result = linregress(area, rent)
print(f"slope={result.slope:.3f}, intercept={result.intercept:.3f}")
print(f"R²={result.rvalue ** 2:.3f}, p={result.pvalue:.2e}")

predicted = result.intercept + result.slope * area
residuals = rent - predicted

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(10, 4))
ax1.scatter(area, rent)
ax1.plot(area, predicted, color="red")
ax1.set_xlabel("Площа, м²")
ax1.set_ylabel("Оренда, тис. грн/міс")
ax1.set_title("Регресійна пряма")

ax2.scatter(area, residuals)
ax2.axhline(0, color="gray", linestyle="--")
ax2.set_xlabel("Площа, м²")
ax2.set_ylabel("Залишок")
ax2.set_title("Графік залишків")
```

Результат: `slope ≈ 0.261`, `intercept ≈ 4.752`, `R² ≈ 0.914`,
`p ≈ 1.2·10⁻⁶`.

**Що тут відбувається.** Рівняння регресії — `оренда ≈ 4.75 + 0.261 ×
площа`: кожен додатковий квадратний метр площі пов'язаний зі
зростанням очікуваної оренди в середньому на ≈261 грн (0.261 тис.
грн), а перетин 4.75 тис. грн — формальне (і не завжди змістовне)
значення оренди при площі 0 м², яке саме по собі не інтерпретується
буквально, бо жодна квартира такої площі не існує. `R² ≈ 0.914` означає,
що 91.4% розкиду цін оренди в цій вибірці пояснюється лише площею;
мале p-value підтверджує, що нахил статистично значуще відрізняється
від нуля. Графік залишків не показує явної форми (точки розкидані
приблизно однаково по обидва боки нуля на всьому діапазоні площ) — це
підтверджує, що лінійна модель тут доречна, а не тільки формально
"добре пояснює дисперсію".

Оцінюється правильність побудови моделі й обчислених коефіцієнтів
саме для вашого варіанта, а також якість аналізу графіка залишків:
Завдання 3 не вважається виконаним, якщо відповідь обмежується "залишки
виглядають нормально" без опису конкретної форми (чи її відсутності)
на вашому власному графіку. Окремо оцінюється явне розрізнення
прогнозу в межах діапазону й екстраполяції за його межі в Завданні 4.
