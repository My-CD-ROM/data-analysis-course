**Код побудови набору** (підставте значення свого варіанта — це лише
генерація вихідних даних, самі завдання нижче виконуються окремо):

```python
import numpy as np
import pandas as pd

np.random.seed(42)
city = "..."          # ваше місто з таблиці варіантів
mean_temp = ...        # середньорічна температура вашого варіанта, °C
amplitude = ...         # сезонна амплітуда вашого варіанта, °C
hum_base = ...          # базова вологість вашого варіанта, %

rows = []
for month in range(1, 13):
    temp = mean_temp + amplitude * np.cos((month - 7) / 12 * 2 * np.pi) + np.random.normal(0, 1.0)
    humidity = hum_base + np.random.normal(0, 5.0)
    if temp < 8:
        opal_days = 30       # опалювальний період триває весь місяць
    elif temp < 12:
        opal_days = 15       # опалювальний період триває частину місяця
    else:
        opal_days = 0        # опалення не потрібне

    cost = (
        200
        - 9.0 * temp
        + 0.6 * humidity
        + 2.5 * opal_days
        + np.random.normal(0, 15)
    )
    rows.append({
        "місто": city, "місяць": month,
        "температура": round(temp, 1),
        "вологість": round(humidity, 1),
        "опалювальні_дні": opal_days,
        "витрати_на_опалення": round(cost, 1),
    })

heating = pd.DataFrame(rows)   # 12 рядків — по одному на кожен місяць року
```

Зверніть увагу: `температура` й `опалювальні_дні` обидві виводяться з
однієї й тієї самої сезонної хвилі (холодний місяць — і низька
температура, і повний опалювальний період), тож апріорі очікувано, що
ці два стовпці в даних сильно пов'язані між собою — саме це знадобиться
для Завдання 4.

## Приклад: наскрізна демонстрація

Розберіть цей приклад — **не** ваш варіант і не тема опалення —
перш ніж переходити до завдань. Дані: результат письмового екзамену
25 студентів залежно від кількості годин самостійної підготовки та
відсотка відвідуваності занять.

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm
from statsmodels.stats.outliers_influence import variance_inflation_factor

students = pd.DataFrame({
    "години_навчання": [2.9, 7.2, 15.0, 2.4, 5.7, 2.9, 7.4, 14.0, 7.5, 12.5,
                         3.3, 17.6, 4.4, 5.2, 10.9, 17.5, 15.7, 19.5, 15.7,
                         8.9, 9.4, 14.8, 6.9, 17.4, 18.4],
    "відвідуваність_%": [88, 76, 58, 65, 64, 66, 73, 77, 61, 90, 86, 92, 63,
                          81, 83, 69, 71, 91, 80, 95, 75, 91, 93, 89, 94],
    "бал_за_екзамен": [69.9, 89.2, 95.3, 59.9, 68.8, 58.5, 80.5, 85.6, 71.6,
                        99.7, 76.1, 100.0, 60.1, 79.9, 88.3, 100.0, 94.3,
                        100.0, 100.0, 93.2, 80.5, 98.5, 81.1, 100.0, 100.0],
})

X = sm.add_constant(students[["години_навчання", "відвідуваність_%"]])
y = students["бал_за_екзамен"]

model = sm.OLS(y, X).fit()
print(model.summary())
```

Ключові рядки виводу `.summary()`:

```
Dep. Variable:         бал_за_екзамен   R-squared:                       0.865
Model:                            OLS   Adj. R-squared:                  0.853
...
====================================================================================
                       coef    std err          t      P>|t|      [0.025      0.975]
------------------------------------------------------------------------------------
const               38.2281      7.498      5.098      0.000      22.677      53.779
години_навчання      2.0189      0.207      9.732      0.000       1.589       2.449
відвідуваність_%     0.3268      0.099      3.290      0.003       0.121       0.533
```

**Що тут відбувається.** Обидва коефіцієнти статистично значущі
(`P>|t| < 0.01` для обох). Інтерпретація за інших рівних умов: за
незмінної відвідуваності кожна додаткова година самостійної підготовки
підвищує очікуваний бал на 2.02 пункти; за незмінної кількості годин
підготовки кожен додатковий відсоток відвідуваності підвищує очікуваний
бал на 0.33 пункти. Adjusted R² (0.853) трохи нижчий за звичайний R²
(0.865) — це очікувано й саме так має бути з двома предикторами на
25 спостереженнях (штраф Лекції 17 невеликий, бо `k = 2` мале порівняно
з `n = 25`).

Перевірка мультиколінеарності:

```python
for i, col in enumerate(X.columns):
    if col == "const":
        continue
    print(col, round(variance_inflation_factor(X.values, i), 2))

# години_навчання      1.12
# відвідуваність_%     1.12
```

VIF для обох предикторів близький до 1 — студенти, які готуються
більше годин, у цьому наборі не є систематично тими самими студентами,
які й відвідують більше занять (кореляція між двома предикторами
слабка), тож окремо оцінені коефіцієнти надійні.

Діагностика залишків:

```python
import matplotlib.pyplot as plt

fitted = model.fittedvalues
residuals = model.resid

fig, ax = plt.subplots()
ax.scatter(fitted, residuals)
ax.axhline(0, color="red", linestyle="--")
ax.set_xlabel("Передбачений бал")
ax.set_ylabel("Залишок")
```

Кореляція між залишками й передбаченими значеннями практично нульова
(`corr(residuals, fitted) ≈ 0`), і на графіку немає видимої лійки чи
дуги — розкид залишків приблизно однаковий по всьому діапазону
передбачених балів, отже, припущення гомоскедастичності не
суперечить цим даним.

## Підсумок заняття

- Побудовано дві моделі множинної регресії (`statsmodels.OLS` із
  `sm.add_constant()`) на власному кліматичному варіанті — з двома і з
  трьома предикторами.
- Коефіцієнти проінтерпретовано "за інших рівних умов" у реальних
  одиницях, з опорою на p-value кожного коефіцієнта.
- Мультиколінеарність перевірено формально через VIF, а не "на око" —
  з явним поясненням, чому знайдений результат (проблема чи її
  відсутність) логічно випливає з побудови даних.
- R² і adjusted R² порівняно при додаванні третього предиктора — і
