варіанта математично (змінні, цільова функція, обмеження) ще **до**

## Приклад: наскрізна демонстрація

Розберіть цей приклад — **не** копіювати на свій варіант, задача тут
демонстраційна і навмисно іншого типу (складання раціону, а не
виробниче планування): потрібно визначити найдешевший добовий раціон
для тварини з двох кормів за умови виконання мінімальних вимог до
живлення.

Корм **комбікорм** (`x1`, кг/добу) коштує 6 грн/кг, містить 150 г
протеїну і 10 МДж енергії на кілограм. Корм **сіно** (`x2`, кг/добу)
коштує 5 грн/кг, містить 100 г протеїну і 15 МДж енергії на кілограм.
Добова норма — не менше 900 г протеїну і не менше 75 МДж енергії;
тварина фізично не може з'їсти більше 12 кг корму на добу. Потрібно
мінімізувати вартість раціону.

**Формалізація.** Змінні: `x1` — кг комбікорму на добу, `x2` — кг сіна
на добу.

```
мінімізувати   6*x1 + 5*x2

150*x1 + 100*x2 >= 900   (протеїн, г)
10*x1 + 15*x2  >= 75     (енергія, МДж)
x1 + x2 <= 12             (фізична межа поїдання, кг)
x1 >= 0, x2 >= 0
```

Тут, на відміну від прикладу лекції, задача — вже пряма мінімізація
(вартості), тож інвертувати знак цільової функції не потрібно. Але два
перші обмеження записані через `>=`, а `linprog` приймає лише форму
`A_ub @ x <= b_ub` — обидва потрібно домножити на `-1`, перш ніж
передавати в код:

```python
from scipy.optimize import linprog

c = [6, 5]   # вартість, грн/кг -- пряма мінімізація

A_ub = [
    [-150, -100],   # протеїн: 150x1 + 100x2 >= 900  -> помножено на -1
    [-10, -15],      # енергія: 10x1 + 15x2 >= 75     -> помножено на -1
    [1, 1],          # фізична межа поїдання: x1 + x2 <= 12
]
b_ub = [-900, -75, 12]

res = linprog(
    c, A_ub=A_ub, b_ub=b_ub,
    bounds=[(0, None), (0, None)],
    method="highs",
)
print(res.x, res.fun, res.status, res.message)
# [4.8 1.8] 37.8 0 Optimization terminated successfully. ...
print(res.slack)
# [0.  0.  5.4]
```

**Інтерпретація.** Оптимальний раціон — 4.8 кг комбікорму і 1.8 кг сіна
на добу, вартістю 37.8 грн. Обидва обмеження на живлення (протеїн і
енергія) активні (`slack = 0`): раціон дає рівно 900 г протеїну і рівно
75 МДж енергії — точно на межі норми, без запасу, бо будь-яке
"перевиконання" норми лише додає вартості без користі для мінімізації.
Обмеження на фізичну межу поїдання неактивне (`slack = 5.4` кг): тварина
могла б з'їсти ще майже 5.4 кг корму, але це нічого не покращило б —
дешевший спосіб виконати норму живлення вже знайдено при меншій
загальній масі раціону.

## Завдання 2. Розв'язання через linprog

Реалізуйте задачу з Завдання 1 засобами `scipy.optimize.linprog` з
`method="highs"`. Не забудьте: `linprog` мінімізує, тож для

Виведіть `res.x`, `res.fun` (і нагадайте собі, що справжній прибуток —
`-res.fun`), `res.status` і `res.message`. Письмово підтвердьте, що
`res.status == 0` перш ніж переходити до інтерпретації результату.

## Завдання 3. Інтерпретація оптимального розв'язку

Письмово інтерпретуйте `res.x` у змістовних одиницях сценарію: скільки
одиниць виробу А і виробу Б варто виробляти на тиждень і який
максимальний тижневий прибуток це дає. Якщо отримані кількості
дробові, поясніть словами, як це узгоджується з тим, що кількість
одиниць продукції в реальності має бути цілою (Лекція 19, огляд
цілочислової оптимізації) — чи достатньо тут просто округлити
результат, і чому округлення не завжди дає гарантовано найкращий
цілочисловий розв'язок.

## Завдання 4. Активні обмеження

Обчисліть `res.slack` для всіх трьох ресурсних обмежень вашого
варіанта (або скористайтесь фактичним використанням ресурсів,
порівнявши його з лімітом з таблиці). Письмово вкажіть, які ресурси
активні (використані повністю) і які мають запас. Поясніть, що це
означає для бізнес-сценарію: у розширення якого саме ресурсу варто
інвестувати, щоб підняти тижневий прибуток, а розширення якого ресурсу
нічого не змінить, оскільки він і без того не є вузьким місцем.

## Завдання 5. What-if: зміна ресурсного обмеження

   збільшився прибуток, і чи змінилась структура випуску (співвідношення
   виробу А до виробу Б)?
2. Тепер зробіть те саме для ресурсу, який виявився **неактивним** у
   Завданні 4: збільште його ліміт на 50% і розв'яжіть задачу знову.
   Письмово поясніть отриманий результат (чи змінився прибуток, і
   чому) з прямим посиланням на ідею з лекції: "активне обмеження — це
