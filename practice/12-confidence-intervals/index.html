    Практика 12. Довірчі інтервали для середнього і частки¶

    Мета заняття: побудувати довірчий інтервал для середнього (через t-розподіл, бо σ невідоме) і для частки (через нормальне наближення) на власній вибірці, порівняти ширину інтервалу при різних рівнях довіри й письмово сформулювати коректну інтерпретацію результату — без поширеної помилки "95% ймовірності, що істинне значення в цьому інтервалі" (Лекція 12).

    Приклад: наскрізна демонстрація¶

    Розберіть цей приклад — контроль ваги пачок чаю на виробництві (номінал на етикетці — 100 г) — перш ніж переходити до власного варіанта. Це інший, демонстраційний набір: скопіювати код і підставити свої числа не вийде, обчислення для вашого варіанта потрібно робити окремо.

    import numpy as np
from scipy import stats

np.random.seed(42)
weights = np.random.normal(loc=98.5, scale=3.0, size=35)   # грами, 35 пачок

mean = weights.mean()
s = weights.std(ddof=1)          # ddof=1 — вибіркове відхилення, оцінка σ
n = len(weights)
se = s / np.sqrt(n)

# 1. довірчий інтервал для середньої ваги пачки (σ невідоме → t-розподіл)
ci_mean = stats.t.interval(0.95, df=n - 1, loc=mean, scale=se)
print(mean, s, ci_mean)            # 98.1  2.8  (97.14, 99.06)

# 2. частка пачок, недоважених нижче номіналу 100 г
underweight = weights < 100
p_hat = underweight.mean()
n_p, n_1p = n * p_hat, n * (1 - p_hat)
print(p_hat, n_p, n_1p)             # 0.771  27.0  8.0 — обидва ≥ 5, наближення прийнятне

se_p = np.sqrt(p_hat * (1 - p_hat) / n)
ci_prop = stats.norm.interval(0.95, loc=p_hat, scale=se_p)
print(ci_prop)                      # (0.632, 0.911)

    Що тут відбувається. Середня вага вибірки (98.1 г) обчислена лише за 35 пачками, тому це точкова оцінка — саме тому й будується інтервал навколо неї. stats.t.interval(0.95, df=n-1, loc=mean, scale=se) використовує t-розподіл, а не нормальний, бо σ (справжнє відхилення процесу пакування) невідоме — маємо лише s, обчислене за цими 35 вимірюваннями; результат (97.14, 99.06) — діапазон, у якому з довірою 95% (у сенсі частки влучень при повторенні процедури, а не ймовірності для цього одного числа — Лекція 12) лежить справжня середня вага пачки на цій лінії. Для частки underweight перевірка n_p ≥ 5 і n_1p ≥ 5 — це саме умова коректності нормального наближення з лекції: тут 8.0 — межове, але прийнятне значення; якби воно було, наприклад, 2, довірчий інтервал за цією формулою вважався би ненадійним.

    Завдання 1. Вибірка денних температур свого варіанта¶

    Візьміть липневу середньомісячну температуру свого варіанта з таблиці й згенеруйте вибірку з 30 "денних" температур навколо неї — так само, як у Практиці 10:

    np.random.seed(<номер вашого варіанта>)
daily_temps = np.random.normal(loc=<липнева температура вашого міста>, scale=2.5, size=30)

    Виведіть отриманий масив і його .mean(), .std(ddof=1).

    Завдання 2. Довірчий інтервал для середньої температури¶

    1. Обчисліть стандартну похибку se = s / np.sqrt(n), де s — вибіркове стандартне відхилення (ddof=1) вашої вибірки daily_temps.
    2. Побудуйте 95% довірчий інтервал для середньої температури через stats.t.interval() — саме t-розподіл, бо справжнє σ клімату вашого міста невідоме, є лише вибіркове s.
    3. Письмово поясніть, чому тут не можна використовувати z-критичне значення замість t-критичного (підказка: яка умова з лекції тут не виконана).

    Завдання 3. Довірчий інтервал для частки¶

    1. Порахуйте частку p_hat днів вашої вибірки, коли температура перевищила липневе табличне значення вашого міста (тобто (daily_temps > <липнева температура з таблиці>).mean()).
    2. Перевірте умову коректності нормального наближення: обчисліть n * p_hat і n * (1 - p_hat) і письмово підтвердьте, чи обидва числа достатньо великі для довіри до формули.
    3. Побудуйте 95% довірчий інтервал для цієї частки через stats.norm.interval().
    4. Оскільки вибірка згенерована симетрично навколо липневого значення, теоретично "справжня" частка днів вище цього порогу — близько 0.5. Перевірте: чи потрапляє 0.5 у ваш обчислений інтервал? Якщо ні — письмово поясніть, чому одна конкретна вибірка з 30 спостережень могла дати інтервал, що не накрив теоретичне значення (зв'язок із поняттям "95% довіри" з лекції — 5% інтервалів саме такі).

    Завдання 4. Ширина інтервалу при різних рівнях довіри¶

    1. Для тієї самої вибірки daily_temps побудуйте довірчий інтервал для середньої температури тричі — при рівнях довіри 90%, 95% і 99% (stats.t.interval(0.90, ...), stats.t.interval(0.95, ...), stats.t.interval(0.99, ...)).
    2. Для кожного випадку обчисліть ширину інтервалу (верхня межа мінус нижня) і зведіть три результати в таблицю чи список.
    3. Письмово поясніть, чому ширина зростає саме в цьому порядку, і що довелось би "заплатити" (яким показником), щоб отримати вужчий інтервал при тому самому рівні довіли 99%.

    Завдання 5. Інтерпретація результату словами¶

    Візьміть свій 95% довірчий інтервал для середньої температури з Завдання 2 і письмово (2–4 речення) поясніть, що саме він означає — без формулювання "з ймовірністю 95% справжня середня температура лежить у цьому інтервалі". Сформулюйте це через повторення процедури вибирання (як у Лекції 12): що б відбувалося, якби згенерувати ще 100 таких вибірок і побудувати 100 інтервалів тим самим способом.

    Що здати й оцінюється¶

    Здайте ноутбук (.ipynb) із зазначеним номером варіанта (містом), згенерованою вибіркою, виконаними Завданнями 1–5 і короткими письмовими відповідями на контрольні питання:

    • Яка різниця між точковою оцінкою і довірчим інтервалом — чому саме число (наприклад, x̄) недостатньо для повної відповіді?
    • Чому для довірчого інтервалу середнього при невідомому σ і не дуже великому n використовують t-розподіл, а не звичайний нормальний?
    • Що насправді означає "95% довіри" — сформулюйте правильно, назвавши явно, чому поширене формулювання через "ймовірність для цього інтервалу" є помилковим.
    • Які саме три фактори визначають ширину довірчого інтервалу, і як кожен з них на неї впливає?

    Оцінюється правильність обчислених інтервалів саме для вашого варіанта (використання t- чи z-розподілу там, де це доречно), коректність перевірки умови для частки та повнота й коректність письмових відповідей — особливо чи не зісковзнули відповіді в поширену помилкову інтерпретацію "95% довіри".

    Підсумок заняття¶

    • Для власної вибірки денних температур побудовано довірчий інтервал середнього через t-розподіл (σ невідоме) і довірчий інтервал частки через нормальне наближення, з перевіркою умови його застосовності.
    • Порівняно ширину інтервалу середнього при трьох рівнях довіри (90/95/99%) на тих самих даних — і явно сформульовано обмін між рівнем довіри і шириною.
    • Письмово сформульовано коректну, "частотну" інтерпретацію довірчого інтервалу — без поширеної помилки про ймовірність для одного вже обчисленого інтервалу.
