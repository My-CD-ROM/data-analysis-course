    Практика 17. Проста лінійна регресія: побудова моделі, коефіцієнти, залишки, коефіцієнт детермінації¶

    Мета заняття: для тієї самої пари змінних, для якої в Практиці 16 обчислювалась кореляція, побудувати рівняння простої лінійної регресії (scipy.stats.linregress, Лекція 16), інтерпретувати нахил і перетин у змістовних одиницях, оцінити якість моделі через R² і перевірити її адекватність графіком залишків — а не лише числом R².

    Код побудови набору (той самий, що в Практиці 16 — якщо ноутбук продовжує той самий, climate уже готовий; якщо це новий ноутбук, підставте своє місто й свій рядок температур):

    import numpy as np
import pandas as pd

np.random.seed(<номер вашого варіанта>)
city = "..."
monthly_temp = [...]   # 12 значень вашого варіанта, Січ..Гру

months = ["Січ", "Лют", "Бер", "Кві", "Тра", "Чер",
          "Лип", "Сер", "Вер", "Жов", "Лис", "Гру"]

rows = []
for month, temp in zip(months, monthly_temp):
    heating_days = np.clip(18 - temp + np.random.normal(0, 1.5), 0, 30)
    heating_days = round(heating_days)
    cost = 0.15 * heating_days + np.random.normal(0, 1.0)
    cost = round(max(cost, 0), 1)
    rows.append({
        "місто": city, "місяць": month, "температура": temp,
        "опалювальні_дні": heating_days, "витрати_на_опалення": cost,
    })

climate = pd.DataFrame(rows)

    Приклад: наскрізна демонстрація¶

    Розберіть цей приклад — площа квартири й ціна оренди для 12 квартир одного району — не копіюйте на свій варіант: обчислення для власного набору "температура / витрати на опалення" виконуються окремо в завданнях нижче.

    import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import linregress

area = np.array([28, 32, 35, 40, 45, 48, 52, 58, 63, 68, 75, 82])          # м²
rent = np.array([14.5, 13.6, 13.9, 12.4, 16.2, 16.9,
                  18.4, 19.3, 21.6, 22.3, 23.0, 28.3])                     # тис. грн/міс

result = linregress(area, rent)
print(f"slope={result.slope:.3f}, intercept={result.intercept:.3f}")
print(f"R²={result.rvalue ** 2:.3f}, p={result.pvalue:.2e}")

predicted = result.intercept + result.slope * area
residuals = rent - predicted

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(10, 4))
ax1.scatter(area, rent)
ax1.plot(area, predicted, color="red")
ax1.set_xlabel("Площа, м²")
ax1.set_ylabel("Оренда, тис. грн/міс")
ax1.set_title("Регресійна пряма")

ax2.scatter(area, residuals)
ax2.axhline(0, color="gray", linestyle="--")
ax2.set_xlabel("Площа, м²")
ax2.set_ylabel("Залишок")
ax2.set_title("Графік залишків")

    Результат: slope ≈ 0.261, intercept ≈ 4.752, R² ≈ 0.914, p ≈ 1.2·10⁻⁶.

    Що тут відбувається. Рівняння регресії — оренда ≈ 4.75 + 0.261 × площа: кожен додатковий квадратний метр площі пов'язаний зі зростанням очікуваної оренди в середньому на ≈261 грн (0.261 тис. грн), а перетин 4.75 тис. грн — формальне (і не завжди змістовне) значення оренди при площі 0 м², яке саме по собі не інтерпретується буквально, бо жодна квартира такої площі не існує. R² ≈ 0.914 означає, що 91.4% розкиду цін оренди в цій вибірці пояснюється лише площею; мале p-value підтверджує, що нахил статистично значуще відрізняється від нуля. Графік залишків не показує явної форми (точки розкидані приблизно однаково по обидва боки нуля на всьому діапазоні площ) — це підтверджує, що лінійна модель тут доречна, а не тільки формально "добре пояснює дисперсію".

    Завдання 1. Побудова регресійної моделі¶

    1. Застосуйте scipy.stats.linregress() до пари climate["температура"] (X) і climate["витрати_на_опалення"] (Y) вашого варіанта.
    2. Випишіть рівняння регресії у вигляді витрати ≈ b0 + b1 × температура з конкретними числами (округленими до трьох знаків).
    3. Письмово інтерпретуйте нахил b1 у змістовних одиницях: на скільки тис. грн у середньому змінюються витрати на опалення при зростанні середньомісячної температури на 1°C, і чи логічний знак цього нахилу (позитивний чи негативний), зважаючи на природу залежності.

    Завдання 2. Коефіцієнт детермінації¶

    1. Обчисліть R² двома способами: через result.rvalue ** 2 і через пряму формулу 1 - SS_залишків / SS_загальна (обчисливши обидві суми квадратів самостійно), і переконайтесь, що результати збігаються.
    2. Порівняйте отримане R² зі значенням r ** 2, обчисленим у Практиці 16 для тієї самої пари змінних — переконайтесь, що це те саме число (Лекція 16: для простої регресії R² = r²).
    3. Письмово інтерпретуйте R² вашої моделі словами: яку частку розкиду витрат на опалення пояснює температура, і яка частка лишається непоясненою.

    Завдання 3. Графік залишків і оцінка адекватності моделі¶

    1. Обчисліть залишки (фактичні витрати - передбачені витрати) для кожного з 12 місяців вашого набору й побудуйте графік залишків (вісь X — температура або номер місяця, вісь Y — залишок, з горизонтальною лінією на нулі).
    2. Уважно розгляньте отриманий графік і письмово опишіть, чи є в ньому видима форма (наприклад, залишки систематично додатні в одній частині діапазону температур і від'ємні в іншій), чи вони розкидані без явної структури.
    3. Зважаючи на те, що "витрати_на_опалення" в коді генерації штучно обмежені знизу нулем (max(cost, 0)) — тобто не можуть бути від'ємними, навіть коли пряма лінія формально передбачає для теплих місяців від'ємне значення, — письмово поясніть, чи саме ця особливість може створювати структуру у ваших залишках для найтепліших місяців вашого варіанта, і як це узгоджується з попередженням Лекції 16 про те, що навіть непогане R² не гарантує відсутності прихованої нелінійності.

    Завдання 4. Прогноз і застереження щодо екстраполяції¶

    1. Використовуючи рівняння з Завдання 1, обчисліть прогнозовані витрати на опалення для температури -10°C.
    2. Порівняйте це значення x = -10°C з фактичним діапазоном температур вашого варіанта (мінімум і максимум серед 12 місячних значень) і письмово визначте, чи це прогноз усередині спостереженого діапазону, чи екстраполяція за його межі.
    3. Якщо це екстраполяція — письмово поясніть, чому довіра до такого прогнозу повинна бути нижчою, ніж до прогнозу для температури, що лежить усередині спостереженого діапазону (з посиланням на те, що модель ніяк не перевірена на даних поза цим діапазоном).

    Завдання 5. Порівняння з коефіцієнтом кореляції¶

    Візьміть значення p-value з linregress() (Завдання 1) і значення p-value з pearsonr(), обчислене для тієї самої пари змінних у Практиці 16, Завдання 2. Письмово поясніть, чому ці два p-value виявляються однаковими (чи дуже близькими) числами — що спільного між H0 "нахил регресії дорівнює нулю" і H0 "коефіцієнт кореляції дорівнює нулю" для простої регресії з одним предиктором.

    Що здати й оцінюється¶

    Здайте ноутбук (.ipynb) із зазначеним номером варіанта (містом), побудованою моделлю регресії, виконаними Завданнями 1–5 і короткими письмовими відповідями на контрольні питання:

    • Чи можете пояснити, чому метод найменших квадратів мінімізує саме суму квадратів залишків, а не суму самих залишків чи їхніх модулів?
    • Що означає коефіцієнт нахилу b1 змістовно для вашої пари змінних, і чим ця інтерпретація відрізняється від інтерпретації коефіцієнта кореляції r для тієї самої пари?
    • Чому високий R² сам по собі не є достатньою підставою вважати лінійну модель адекватною — що саме може показати графік залишків, чого не показує одне число R²?
    • Що змінюється в надійності прогнозу, коли значення x, для якого робиться прогноз, виходить за межі спостереженого діапазону даних?

    Оцінюється правильність побудови моделі й обчислених коефіцієнтів саме для вашого варіанта, а також якість аналізу графіка залишків: Завдання 3 не вважається виконаним, якщо відповідь обмежується "залишки виглядають нормально" без опису конкретної форми (чи її відсутності) на вашому власному графіку. Окремо оцінюється явне розрізнення прогнозу в межах діапазону й екстраполяції за його межі в Завданні 4.

    Підсумок заняття¶

    • Побудовано рівняння простої лінійної регресії витрати ≈ b0 + b1 × температура для власного варіанта методом найменших квадратів (scipy.stats.linregress), з інтерпретацією нахилу в змістовних одиницях.
    • Обчислено й проінтерпретовано коефіцієнт детермінації R², з перевіркою рівності R² = r² для простої регресії.
    • Побудовано і проаналізовано графік залишків власної моделі — з явним висновком про наявність чи відсутність прихованої структури, а не лише посиланням на значення R².
    • Зроблено прогноз для нового значення X з явним розрізненням прогнозу в межах спостереженого діапазону й екстраполяції за його межі.
