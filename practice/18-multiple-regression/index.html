    Практика 18. Множинна лінійна регресія: відбір предикторів, інтерпретація коефіцієнтів, діагностика залишків¶

    Мета заняття: побудувати модель множинної лінійної регресії (statsmodels.OLS із sm.add_constant()) на власному варіанті, інтерпретувати коефіцієнти "за інших рівних умов", перевірити мультиколінеарність предикторів через VIF, порівняти звичайний і adjusted R² при додаванні третього предиктора та провести діагностику залишків — усе за апаратом Лекції 17.

    Варіанти¶

    Дані варіанта — той самий кліматичний набір, що й у Практиці 15 (середньорічна температура й сезонна амплітуда свого міста), і та сама базова вологість, що в Практиці 14 (стовпець "Норма"). Додатково моделюються умовні щомісячні витрати на опалення — залежна змінна, яку прогнозуватимуть Завдання 1–5.

    Код побудови набору (підставте значення свого варіанта — це лише генерація вихідних даних, самі завдання нижче виконуються окремо):

    import numpy as np
import pandas as pd

np.random.seed(42)
city = "..."          # ваше місто з таблиці варіантів
mean_temp = ...        # середньорічна температура вашого варіанта, °C
amplitude = ...         # сезонна амплітуда вашого варіанта, °C
hum_base = ...          # базова вологість вашого варіанта, %

rows = []
for month in range(1, 13):
    temp = mean_temp + amplitude * np.cos((month - 7) / 12 * 2 * np.pi) + np.random.normal(0, 1.0)
    humidity = hum_base + np.random.normal(0, 5.0)
    if temp < 8:
        opal_days = 30       # опалювальний період триває весь місяць
    elif temp < 12:
        opal_days = 15       # опалювальний період триває частину місяця
    else:
        opal_days = 0        # опалення не потрібне

    cost = (
        200
        - 9.0 * temp
        + 0.6 * humidity
        + 2.5 * opal_days
        + np.random.normal(0, 15)
    )
    rows.append({
        "місто": city, "місяць": month,
        "температура": round(temp, 1),
        "вологість": round(humidity, 1),
        "опалювальні_дні": opal_days,
        "витрати_на_опалення": round(cost, 1),
    })

heating = pd.DataFrame(rows)   # 12 рядків — по одному на кожен місяць року

    Зверніть увагу: температура й опалювальні_дні обидві виводяться з однієї й тієї самої сезонної хвилі (холодний місяць — і низька температура, і повний опалювальний період), тож апріорі очікувано, що ці два стовпці в даних сильно пов'язані між собою — саме це знадобиться для Завдання 4.

    Приклад: наскрізна демонстрація¶

    Розберіть цей приклад — не ваш варіант і не тема опалення — перш ніж переходити до завдань. Дані: результат письмового екзамену 25 студентів залежно від кількості годин самостійної підготовки та відсотка відвідуваності занять.

    import numpy as np
import pandas as pd
import statsmodels.api as sm
from statsmodels.stats.outliers_influence import variance_inflation_factor

students = pd.DataFrame({
    "години_навчання": [2.9, 7.2, 15.0, 2.4, 5.7, 2.9, 7.4, 14.0, 7.5, 12.5,
                         3.3, 17.6, 4.4, 5.2, 10.9, 17.5, 15.7, 19.5, 15.7,
                         8.9, 9.4, 14.8, 6.9, 17.4, 18.4],
    "відвідуваність_%": [88, 76, 58, 65, 64, 66, 73, 77, 61, 90, 86, 92, 63,
                          81, 83, 69, 71, 91, 80, 95, 75, 91, 93, 89, 94],
    "бал_за_екзамен": [69.9, 89.2, 95.3, 59.9, 68.8, 58.5, 80.5, 85.6, 71.6,
                        99.7, 76.1, 100.0, 60.1, 79.9, 88.3, 100.0, 94.3,
                        100.0, 100.0, 93.2, 80.5, 98.5, 81.1, 100.0, 100.0],
})

X = sm.add_constant(students[["години_навчання", "відвідуваність_%"]])
y = students["бал_за_екзамен"]

model = sm.OLS(y, X).fit()
print(model.summary())

    Що тут відбувається. Обидва коефіцієнти статистично значущі (P>|t| < 0.01 для обох). Інтерпретація за інших рівних умов: за незмінної відвідуваності кожна додаткова година самостійної підготовки підвищує очікуваний бал на 2.02 пункти; за незмінної кількості годин підготовки кожен додатковий відсоток відвідуваності підвищує очікуваний бал на 0.33 пункти. Adjusted R² (0.853) трохи нижчий за звичайний R² (0.865) — це очікувано й саме так має бути з двома предикторами на 25 спостереженнях (штраф Лекції 17 невеликий, бо k = 2 мале порівняно з n = 25).

    Перевірка мультиколінеарності:

    for i, col in enumerate(X.columns):
    if col == "const":
        continue
    print(col, round(variance_inflation_factor(X.values, i), 2))

# години_навчання      1.12
# відвідуваність_%     1.12

    VIF для обох предикторів близький до 1 — студенти, які готуються більше годин, у цьому наборі не є систематично тими самими студентами, які й відвідують більше занять (кореляція між двома предикторами слабка), тож окремо оцінені коефіцієнти надійні.

    Діагностика залишків:

    import matplotlib.pyplot as plt

fitted = model.fittedvalues
residuals = model.resid

fig, ax = plt.subplots()
ax.scatter(fitted, residuals)
ax.axhline(0, color="red", linestyle="--")
ax.set_xlabel("Передбачений бал")
ax.set_ylabel("Залишок")

    Кореляція між залишками й передбаченими значеннями практично нульова (corr(residuals, fitted) ≈ 0), і на графіку немає видимої лійки чи дуги — розкид залишків приблизно однаковий по всьому діапазону передбачених балів, отже, припущення гомоскедастичності не суперечить цим даним.

    Завдання 2. Інтерпретація коефіцієнтів у реальних одиницях¶

    1. Для кожного з двох коефіцієнтів моделі Завдання 1 письмово сформулюйте інтерпретацію "за інших рівних умов" у реальних одиницях (наприклад: "за незмінної вологості кожен додатковий градус середньомісячної температури змінює витрати на опалення на ... умов. одиниць").
    2. Для кожного коефіцієнта вкажіть його P>|t| і письмово поясніть, чи є підстави (при α = 0.05) вважати цей предиктор статистично значущим за інших рівних умов.

    Завдання 3. Перевірка мультиколінеарності через VIF¶

    1. Обчисліть VIF для обох предикторів моделі Завдання 1 (variance_inflation_factor).
    2. При практичному порозі "VIF > 5 — увага, VIF > 10 — проблема" письмово оцініть, чи є серед двох предикторів проблемний.
    3. Якщо VIF виявився високим для якогось предиктора — поясніть письмово, чому це логічно випливає з того, як побудований код генерації набору (розділ "Варіанти"); якщо VIF низький для обох — поясніть, чому температура й вологість у цьому наборі не пов'язані між собою жорстко (подивіться на код: чи вологість залежить від температури в формулі генерації).

Письмово поясніть результат порівняння: чи виправдав доданий предиктор штраф adjusted R² за додатковий ступінь свободи, і як це узгоджується з тим, що температура й опалювальні_дні, за визначенням із коду генерації, сильно пов'язані між собою (тобто, можливо, варто також глянути на VIF цієї трипредикторної моделі й врахувати це у висновку).

    • Чи можете сформулювати своїми словами, у чому коефіцієнт множинної регресії відрізняється від коефіцієнта простої регресії з тим самим предиктором?
    • Чи розумієте, чому звичайний R² не може зменшитись при додаванні будь-якого нового предиктора, навіть безглуздого, і чому це робить його непридатним для порівняння моделей із різною кількістю предикторів?
    • Що означає VIF предиктора, що дорівнює приблизно 1, і що означає VIF вище 10 — і що з цим варто зробити на практиці?

    Оцінюється правильність побудови обох моделей (з двома і з трьома предикторами) саме для вашого варіанта, коректність інтерпретації коефіцієнтів у реальних одиницях "за інших рівних умов" (а не просто переказ числа з .summary() без контексту), обґрунтованість висновку щодо VIF і щодо вибору між моделлю з двома чи трьома предикторами, а також повнота письмової діагностики залишків.

    Підсумок заняття¶

    • Побудовано дві моделі множинної регресії (statsmodels.OLS із sm.add_constant()) на власному кліматичному варіанті — з двома і з трьома предикторами.
    • Коефіцієнти проінтерпретовано "за інших рівних умов" у реальних одиницях, з опорою на p-value кожного коефіцієнта.
    • Мультиколінеарність перевірено формально через VIF, а не "на око" — з явним поясненням, чому знайдений результат (проблема чи її відсутність) логічно випливає з побудови даних.
    • R² і adjusted R² порівняно при додаванні третього предиктора — і зроблено обґрунтований висновок, чи виправдане ускладнення моделі.
    • Проведено діагностику залишків (графік проти передбачених значень, QQ-plot, критерій Шапіро-Вілка) і порівняно пояснену частку дисперсії з простою регресією одного предиктора з Практики 17.
