## Зміст роботи

* **Крок 1–2:** Перевірка середовища (`np.__version__`), створення базового масиву (`shape`, `dtype`).
* **Завдання 1:** Створення масивів `temps` (Варіант 2 — Львів), `days_in_month`, `month_numbers`.
* **Завдання 2:** Векторизоване переведення в °F, підрахунок днів тепліше 15°C, перевірка суми днів (365).
* **Завдання 3:** Пошук найтеплішого і найхолоднішого місяця (`argmax`, `argmin`), фільтрація від'ємних температур, сортування.
* **Завдання 4:** Двовимірний масив `(3, 12)`, агрегація по осях `axis=1` та `axis=0`, пояснення значення для січня.
* **Завдання 5:** Демонстрація помилки broadcasting при додаванні векторів і виправлення через `.reshape(2, 1)`.
* **Відповіді на контрольні запитання:** Розбір різниці розмірностей, булевої індексації та правил broadcasting.
