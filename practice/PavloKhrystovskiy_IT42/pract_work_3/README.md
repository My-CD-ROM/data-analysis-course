## Налаштування середовища (venv)

Створення та активація віртуального середовища, а також встановлення залежностей:

```bash
# Створення віртуального середовища
python3 -m venv .venv

# Активація (macOS / Linux)
source .venv/bin/activate

# Оновлення pip та встановлення необхідних бібліотек
pip install --upgrade pip
pip install pandas ipykernel nbclient nbformat
```

Для відкриття та перегляду ноутбука в інтерактивному середовищі:

## Короткий список виконаних завдань

1. **Демонстраційний приклад:** Відтворено та розібрано наскрізний демонстраційний приклад (квартальна виручка трьох магазинів: перетворення `wide -> tidy -> wide`, запис/читання CSV і JSON).
2. **Завдання 1. Побудова wide-таблиці свого варіанта:** Зібрано DataFrame у wide-форматі з одним рядком (1 × 13) для Варіанта 2 (місто Львів, 12 місяців хмарності).
3. **Завдання 2. Приведення до tidy (melt):** Виконано депівотування таблиці за допомогою `melt()` у формат трьох стовпців (`місто`, `місяць`, `хмарність`) розмірністю (12 × 3). Надано пояснення, чому кількість рядків збільшилась із 1 до 12.
4. **Завдання 3. Класифікація змінних:** Для кожного стовпця визначено шкалу вимірювання Стівенса (`місто` — номінальна, `місяць` — порядкова, `хмарність` — шкала відношень) з детальним обґрунтуванням вибору.
5. **Завдання 4. Зворотне перетворення й перевірка:** Здійснено зворотну операцію денормалізації через `pivot()`, відновлено початковий порядок стовпців та перевірено повний збіг з оригіналом (`equals() == True`).
6. **Завдання 5. Читання й запис (CSV та JSON):** Записано дані у файли `variant.csv` та `variant.json`, перевірено коректність їх зворотного зчитування назад у DataFrame (`equals() == True`) та проведено порівняльний аналіз структури обох форматів.
7. **Контрольні запитання:** Надано вичерпні письмові відповіді на 3 теоретичні контрольні питання в Markdown-клітинах наприкінці ноутбука.
