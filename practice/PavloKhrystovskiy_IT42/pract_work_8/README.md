2. **Завдання 1 (groupby і agg за роками):**
   - Розраховано середню, мінімальну та максимальну температури за кожен рік (2021–2024).
   - Зроблено висновок щодо відсутності лінійного кліматичного тренду та підтверджено випадковий характер коливань навколо середнього 8.5 °C.

   - Обчислено помісячні середні температури та їхнє стандартне відхилення (`std`).

   - Проведено порівняльний аналіз довгого (tidy) та широкого (wide) форматів, описано їхні переваги для сприйняття людиною та машинної обробки (зв'язок із `pivot` / `melt`).
